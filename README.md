# Классификация музыкальных жанров на GTZAN

Расчётно-графическое задание по дисциплине «Системы искусственного интеллекта и машинное обучение», вариант 42. Приложение определяет один из десяти жанров по шестисекундному аудиофрагменту. Режим до 30 секунд объединяет оценки по полным шестисекундным окнам.

## Запуск на Windows

Установите Python 3.12 и выполните из корня репозитория в PowerShell:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Запустить.cmd
```

Готовые веса находятся в `artifacts/genre_cnn.pt`. В окне приложения нажмите **Открыть аудио** и выберите WAV, FLAC, MP3, OGG, AU или AIFF. Интерфейс показывает жанр, оценки softmax, звуковую волну и log-mel спектрограмму. Кнопка **Прослушать** воспроизводит анализируемый интервал.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `audio_features.py` | Декодирование, нарезка, log-mel спектрограмма и аугментация |
| `prepare.py` | Формирование выборок и кеша признаков |
| `model.py` | Архитектура CNN и применение сохранённых весов |
| `train.py` | Обучение, выбор конфигурации и тестовые метрики |
| `app.py` | Графический интерфейс и анализ из терминала |
| `make_demo.py` | Подготовка и проверка примеров из тестовой выборки |

## Повторное обучение

Скрипт подготовки данных скачивает [архив GTZAN](https://huggingface.co/datasets/marsyas/gtzan/blob/main/data/genres.tar.gz) объёмом около 1,23 ГБ и [фильтрованное разбиение Sturm](https://github.com/boblsturm/GTZAN).

```powershell
.\fetch_data.ps1
& .\.venv\Scripts\python.exe prepare.py
& .\.venv\Scripts\python.exe train.py --threads 4
& .\.venv\Scripts\python.exe make_demo.py
```

Если GTZAN уже распакован, передайте путь к каталогу аудиофайлов через `--dataset` в `prepare.py` и `make_demo.py`. Фрагменты одной записи остаются в одной выборке. При подготовке исключается повреждённый файл `jazz.00054`.

## Результаты на отложенной выборке

| Модель | Accuracy окна 6 с | Accuracy записи | Macro F1 записи |
| --- | ---: | ---: | ---: |
| CNN с аугментацией | 61,1% | 65,2% | 0,638 |
| SVM на MFCC | 57,0% | 66,2% | 0,649 |

В тест вошли 1 449 окон из 290 записей. Конфигурация CNN выбрана по Macro F1 на валидационных записях. После обучения метрики, графики и матрица ошибок доступны в `artifacts`.
